# Hi, I’m Sherifdeen Lawal

I work in robotics perception and state estimation, focusing on helping autonomous systems understand their surroundings and estimate motion reliably.

My projects include deep learning for visual odometry, sensor fusion using an error-state extended Kalman filter, and stereo camera–IMU calibration. I use Python, NumPy, and PyTorch, and I have experience deploying and evaluating models on the Jetson Nano.

Here, I share implementations, experimental results, and lessons from debugging and evaluating these systems.
